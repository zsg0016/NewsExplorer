# NewsExplorer

## Project Description

An app that allows the user to search for articles via keyword(s). The user can create an account and save articles to thier profile.

## Technolgies and Techniques

- HTML
- CSS
- Javascript
- External Fonts using font-face
- BEM File Structure
- React
- React Routing
- API Fetching
- Hooks
